# EMCICT311 - DIGITAL NOTEBOOK

A web-based Digital Notebook application developed for **EMCICT311: Introduction to Software Development**.

## 📖 Project Description
The Digital Notebook is designed to help students store, organize, and access their course notes digitally.  
It provides a clean and simple interface for writing, saving, and viewing notes on any device with internet access.

## ✨ Features
- **Create Notes**: Write and save notes by topic/course
- **Organized Storage**: Keep notes structured for easy access  
- **Responsive Design**: Works on phone, tablet, and desktop
- **Web Based**: No installation needed. Access anywhere

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
